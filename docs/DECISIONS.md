# 实现决策与边界

本实现以用户粘贴的《研势》为产品需求。候选人附件是参考题面；其中长期监控、调度、去重、冷却、版本变更不属于本次两页面市场研判范围。本产品不能作为已完整满足原题面的监控服务宣称提交。

- 使用 Next.js App Router、TypeScript、Tailwind CSS；UI 使用 shadcn/ui 风格的 Button 与 Radix Dialog 源组件。
- 扶摇官方 A 股指数快照接口接入服务端，仅替换行情结构 E01。响应须同时包含三只指数、有效价格与涨跌幅、可用时间戳；其他维度来自版本化合成 fixture。解释仍由确定性模板生成，页面披露未连接大模型。
- DATA_MODE=mock 是可交互演示；DATA_MODE=live 是混合真实与 Demo 的模式。接口缺失、失败或数据不合格时，仅 E01 回退 Demo 并显示明确告知。Key 只在服务端环境变量，不进入 NEXT_PUBLIC_*。
- Demo 校验使用明确固定的“演示校验时钟”，不是把历史数字伪装成实时数据。所有时间含上海时区。
- 用户需求对 0.85、1.15 的边界描述重叠，采用显式不等式优先：≤0.85 收缩、≥1.15 活跃，中间开区间中性。市场宽度 40% 中性、60% 强。
- 四核心维度均须有效。候选分数领先不足 2 分、最高分不足 4 分、或核心证据缺失/冲突/过期，均判为证据不足。可选维度异常仍显示但不参与评分。
- 候选评分使用原始分，未归一化；规则是 MVP 产品启发式，未经过历史统计校准。置信度为证据一致度，非未来涨跌概率。
- 置信度：基础 50，四核心完整 +20，最高分领先至少 3 分 +20，所有有效证据足够新 +10；缺失 -15，冲突 -15，过期 -20。存在核心异常直接 0% 并显示不计算。
- 真实行情结构以三大指数涨跌幅最大差（百分点）计算信号，并在来源抽屉披露；情绪等维度继续使用明确标记的 Demo fixture。未用 AI 补齐行情数字。
