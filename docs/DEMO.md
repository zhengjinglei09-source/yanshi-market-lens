# 90 秒演示脚本

这是演示流程说明，**不是已录制的视频**。使用正常演示场景，始终保留 DEMO DATA 标识。

- 0–12 秒：首页介绍三个研究目标，输入「当前 A 股处于什么状态？」。
- 12–25 秒：点击开始研判，展示五阶段流程、七维计划、事件不可用状态。
- 25–42 秒：报告显示「结构主导」、成长占优与市场宽度偏弱；解释 85% 是证据一致度，不是上涨概率。
- 42–58 秒：点击市场宽度的数字或查看来源，展示 36.8%、1,840/5,000、固定演示时点、合成来源与统计口径。
- 58–68 秒：展示唯一主要矛盾和三条重新评估条件，不把条件表述成未来上涨。
- 68–80 秒：底部选择「市场宽度缺失」并重新研判，展示证据不足与重试入口。
- 80–90 秒：新建研究输入「明天会上涨吗？」，展示合规回复与「研判当前市场」按钮。

可补充：切换 API 失败、过期、冲突场景；点击继续研究的市场风格；解释行业数据未接入的限制。
